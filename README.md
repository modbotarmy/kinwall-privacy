# Kinwall Family — Privacy Policy

Effective November 23, 2026

## Overview

Kinwall Family is a private, self-hosted household management application intended exclusively for personal and family use.

## Google User Data

The application uses Google Calendar authorization to access selected calendars with the user's explicit consent. Calendar information is used to display, create, update, delete, and synchronize household calendar events.

## Data Storage and Security

Application data is stored on a privately managed home server. Access to the application is restricted through authentication and a private network.

## Data Sharing

We do not sell Google user data or use it for advertising, marketing, or AI model training. Google user data is used solely to provide the application's requested functionality.

## Data Retention and Deletion

Calendar information is retained as needed to provide calendar synchronization. Users may disconnect their Google account, revoke application access through their Google Account security settings, and request deletion of locally stored data by contacting the administrator.

## Google API Compliance

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

## Contact

For questions regarding this privacy policy or requests concerning personal data, please contact the household administrator directly. This application is intended exclusively for private household use.
